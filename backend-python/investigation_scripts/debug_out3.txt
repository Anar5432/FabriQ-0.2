CONFIRMED ROOT CAUSE:
1. sobe2 (destination) is ALWAYS 6 (Finished Goods) for complete items
   => Cannot use sobe2 to find intermediate stages
2. sobe1 (source/origin) tells us WHERE items came FROM in the latest transfer
   => sobe1=3 (Kesim) means item just LEFT cutting, now in Tikis
   => sobe1=4 or 5 (Tikis) means item just LEFT sewing, now in Finished Goods

CORRECT APPROACH:
  For items with transfer: use sobe2 (destination) from LATEST transfer
  BUT the 'Ambar' destination (6) means it COMPLETED that stage
  So we need to handle:
    sobe2=3 (Kesim) = item arrived in Cutting dept = K╔Ösim stage
    sobe2=4 or 5 (Tikis) = item arrived in Sewing dept = Tiki┼ƒ stage
    sobe2=6 (Finished Goods) = item completed = Ambar stage
    sobe2=NULL = no transfer yet = Sat─▒┼ƒ stage
